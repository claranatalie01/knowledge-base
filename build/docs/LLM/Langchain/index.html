LangChain Framework

LangChain is a toolkit for building applications powered by large language models (LLMs).
It handles prompts, memory, document search (RAG), and tool calling – all integrated with uv for fast, reproducible Python environments.

Prerequisites​

  • Python 3.11 or higher
  • uv installed (instructions)
  • An OpenAI API key (or other LLM provider key)

1.1 Core Architecture​

LangChain separates execution, integration, and observability into layers.

LayerDomainResponsibilityKey Components
OrchestrationLangGraphStateful multi‑agent workflows, loops, human‑in‑the‑loopStateGraph, MessagesState
Interface Baselangchain-coreExecution primitives, LCEL pipe protocolRunnable, ChatPromptTemplate
Integrationslangchain-communityThird‑party models, vector stores, loadersChroma, ChatOpenAI, PyPDFLoader
ObservabilityLangSmithTracing, cost monitoring, evaluationAutomated trace injection

1.1.1 Component Roles​

ComponentLanguagePurpose
LCEL EnginePython / RustUnified streaming, batch, async
Model I/OPythonPrompts, configs, token schemas
Data RetrievalPythonDocument loading, splitting, embedding
Tool ExecutionPythonFunction‑calling with validation

1.2 Project Structure (uv)​

Use uv to manage dependencies and src/ layout.

langchain-project/
├── pyproject.toml        # Dependencies and config
├── uv.lock               # Lockfile (commit)
├── .python-version       # Python version pin
├── .env                  # API keys (gitignore)
├── src/app_orchestrator/
│   ├── __init__.py
│   ├── tools.py          # @tool definitions
│   ├── chains.py         # LCEL pipelines
│   └── graph.py          # LangGraph state graphs
└── tests/
    ├── conftest.py
    └── test_chains.py

Setup commands:

uv add langchain-core langchain-openai langchain-community
uv add langchain-chroma langchain-text-splitters langsmith
uv add --dev pytest ruff mypy
uv sync

1.3 LCEL – LangChain Expression Language​

LCEL uses the pipe operator | to chain components.

Execution flow:
Input → Prompt → Model → Parser → Output

1.3.1 Runnable Methods​

MethodAsyncBehaviour
invoke(input)ainvokeSingle call, full result
stream(input)astreamYields tokens as they arrive
batch([inputs])abatchParallel processing

1.3.2 Basic Chain Example​

from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_openai import ChatOpenAI

prompt = ChatPromptTemplate.from_messages([
    ("system", "Answer: {question}")
])
model = ChatOpenAI(model="gpt-4o-mini", temperature=0)
parser = StrOutputParser()

chain = prompt | model | parser
answer = chain.invoke({"question": "What is RAG?"})

1.3.3 Flow Helpers​

HelperPurpose
RunnablePassthrough()Pass input unchanged
RunnableLambda(func)Wrap any Python function
RunnableParallel(...)Execute sub‑chains concurrently
from langchain_core.runnables import RunnablePassthrough, RunnableParallel

pipeline = RunnableParallel(
    raw=RunnablePassthrough(),
    upper=lambda x: x["text"].upper()
)

1.4 RAG – Retrieval-Augmented Generation​

RAG allows answering from private documents. Pipeline:

Load → Split → Embed → Store → Retrieve → Generate

1.4.1 Implementation Steps​

1. Load documents

from langchain_community.document_loaders import TextLoader

loader = TextLoader("data/doc.txt")
docs = loader.load()

2. Split into chunks

from langchain_text_splitters import RecursiveCharacterTextSplitter

splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)
chunks = splitter.split_documents(docs)

3. Embed and store

from langchain_openai import OpenAIEmbeddings
from langchain_chroma import Chroma

embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
vectorstore = Chroma.from_documents(chunks, embeddings, persist_directory="./chroma_db")
retriever = vectorstore.as_retriever(search_kwargs={"k": 3})

4. Build RAG chain

from langchain_core.runnables import RunnablePassthrough

def format_docs(docs):
    return "\n\n".join(d.page_content for d in docs)

rag_prompt = ChatPromptTemplate.from_template("""
Context: {context}
Question: {question}
Answer:
""")

rag_chain = (
    {"context": retriever | format_docs, "question": RunnablePassthrough()}
    | rag_prompt
    | model
    | StrOutputParser()
)

answer = rag_chain.invoke("What is the loan period?")

1.4.2 Tuning Guide​

ParameterRecommendedTrade‑off
chunk_size400–800 tokensLarger = more context but more noise
chunk_overlap10–20% of sizePrevents broken sentences
k3–5More chunks = more variety, risk of distraction

1.5 Memory & State Management​

Memory keeps conversation history across turns.

Example with buffer memory:

from langchain_core.chat_history import InMemoryChatMessageHistory
from langchain_core.runnables.history import RunnableWithMessageHistory

# Store sessions in a dict
store = {}

def get_session_history(session_id):
    if session_id not in store:
        store[session_id] = InMemoryChatMessageHistory()
    return store[session_id]

# Prompt must include "{history}"
prompt = ChatPromptTemplate.from_messages([
    ("system", "You are an assistant. History: {history}"),
    ("human", "{input}")
])

chain = prompt | model | parser
chain_with_memory = RunnableWithMessageHistory(
    chain, get_session_history,
    input_messages_key="input",
    history_messages_key="history"
)

response = chain_with_memory.invoke(
    {"input": "My name is Alice"},
    config={"configurable": {"session_id": "user123"}}
)

1.6 Tools & Agents​

Tools let the LLM call external functions. Agents decide when and how to call them.

1.6.1 Define a Tool​

from langchain_core.tools import tool

@tool
def search_catalog(title: str) -> str:
    """Search for a book by title."""
    return f"{title} found on shelf A12."

1.6.2 Create an Agent​

from langgraph.prebuilt import create_react_agent

agent = create_react_agent(
    model=model,
    tools=[search_catalog],
    state_modifier="You are a library assistant. Use the search tool when needed."
)

result = agent.invoke({"messages": [("user", "Where is Dune?")]})
print(result["messages"][-1].content)

Agent cycle: Reason → Act → Observe → Answer (repeat if needed).

1.7 LangGraph – Complex Workflows​

LangGraph handles loops, conditional branching, and multi‑agent coordination.

1.7.1 Simple State Graph​

from langgraph.graph import StateGraph, END
from typing import TypedDict

class State(TypedDict):
    question: str
    answer: str

def route(state):
    if "book" in state["question"].lower():
        return {"answer": "I can help with books."}
    return {"answer": "I only answer book questions."}

graph = StateGraph(State)
graph.add_node("router", route)
graph.set_entry_point("router")
graph.add_edge("router", END)
app = graph.compile()

1.7.2 Supervisor‑Workers (Multi‑Agent)​

from langgraph_supervisor import create_supervisor
from langgraph.prebuilt import create_react_agent

book_agent = create_react_agent(model, [search_catalog], name="book_helper")
hours_agent = create_react_agent(model, [], name="hours_helper")

supervisor = create_supervisor(
    agents=[book_agent, hours_agent],
    model=model,
    prompt="Route book questions to book_helper, hours to hours_helper."
)

1.8 LangSmith – Tracing & Debugging​

LangSmith records every execution step – essential for debugging.

Setup​

import os
os.environ["LANGCHAIN_TRACING_V2"] = "true"
os.environ["LANGCHAIN_API_KEY"] = "lsv2_..."
os.environ["LANGCHAIN_PROJECT"] = "my_project"

After this, every .invoke() is automatically traced. View traces in the LangSmith dashboard.

1.9 Best Practices & Pitfalls​

1.9.1 Safety Rules​

  1. Use temperature=0 for tool calling and routing.
  2. Set recursion limits to prevent infinite loops: recursion_limit=10.
  3. Never use f‑strings to build prompts from user input (risk of injection).
  4. Always bound k in retrievers: search_kwargs={"k": 3}.

1.9.2 Common Issues​

ProblemCauseFix
invoke returns AIMessageMissing output parserAdd | StrOutputParser()
Memory not workingNo {history} in promptInclude {history} placeholder
Agent loops foreverNo iteration limitSet recursion_limit
High token usagechunk_size too largeReduce to 400–600

1.9.3 Production Quality Gates​

# Safe model settings
llm = ChatOpenAI(model="gpt-4o", temperature=0, max_retries=2, timeout=15)

# Controlled batch concurrency
chain.batch(inputs, config={"max_concurrency": 5})
